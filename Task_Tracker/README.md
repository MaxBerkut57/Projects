## 1. Task Tracker: 
- A task tracker is a tool for tracking and managing tasks. This project features a simple command-line interface (CLI) that allows you to track planned, completed, and ongoing tasks.
- Трекер задач — это инструмент для отслеживания задач и управления ими. Этот проект имеет простой интерфейс командной строки (CLI), позволяющий отслеживать запланированные, выполненные и текущие задачи.
