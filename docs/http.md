# HTTP: конспект

## 1. Как это работает
Клиент отправляет запрос, сервер возвращает ответ. (2-3 предложения своими словами.)

## 2. Запрос
Из чего состоит: метод, URL, заголовки, тело. Вставь свой `curl.exe -i -X POST ...` и подпиши части.

## 3. Ответ
Из чего состоит: код статуса, заголовки, тело. Вставь ответ на POST (201 Created), отметь
`Content-Type` и `Location`, объясни, что они значат.

## 4. Методы
| Метод | Что делает | Безопасный | Идемпотентный |
|---|---|---|---|
| GET | получает данные | да | да |
| POST | создаёт ресурс или запускает действие | нет | нет |
| PUT | заменяет ресурс целиком | нет | да |
| PATCH | меняет часть ресурса | нет | нет |
| DELETE | удаляет ресурс | нет | да |

Правило: безопасные это GET, HEAD, OPTIONS, TRACE. Идемпотентные это безопасные плюс PUT и DELETE.
Пример идемпотентности: (свой, одной-двумя строками, про PUT, POST и DELETE).

## 5. Коды ответа
- 2xx успех: 200 OK, 201 Created, 204 No Content
- 3xx перенаправление: 301, 304
- 4xx ошибка клиента: 400, 401, 403, 404, 409, 422
- 5xx ошибка сервера: 500, 502, 503
Для каждого кода (хотя бы для тех, что встречал) допиши одной строкой, когда он приходит.
401 и 403 объясни своими словами.

## 6. Заголовки, которые встретил
`Content-Type`, `Location`, `Cache-Control`, `ETag`: что каждый значит.
